# Visual direction and source lock

The user's 14 supplied September 11 screenshots are the visual authority. The V13.6 package is the equipment authority. The existing O-00–O-14 sequence and combustion kernel remain authoritative application behavior.

| Decision | Reference / requirement | Applied role |
|---|---|---|
| Navy equipment canvas with compact side panels | Whole-heater hero references | Keep the interactive equipment central |
| Orange selected component and heat cues | Exploded anatomy and component inspector references | Selection and heat, not decorative backgrounds |
| Cyan instrumentation / air, blue process, amber fuel | Flow and operator-view references | Distinct physical streams |
| Numbered labels with leaders | Equipment callout references | Location and context, filtered by view distance |
| Actual model thumbnails | Component-library and troubleshooting-gallery references | Screenshots generated from the same GLB renderer; no replacement of interactive views |
| Mobile sheets, compact bottom controls | Supplied mobile reference | Preserve an unobstructed equipment view and touch access |
| Whole/system/component separation | User's exploded-anatomy requirement | Runtime transforms only; original asset and node identities preserved |

The design intentionally keeps rectangular technical panels, thin borders and a restrained 4–6 px radius. No new document library, accounts, standards database or calculation suite is added.
